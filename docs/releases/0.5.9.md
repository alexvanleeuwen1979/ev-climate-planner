# EV Climate Planner 0.5.9

This release removes the legacy accessibility service used to operate the official Kia app on screen. Connect your Kia account in Settings to use remote climate scheduling.

The removed service is a suspected trigger for the Play Protect installation warning reported with 0.5.8. Acceptance by Play Protect on the affected device is still unverified. Keep Play Protect enabled and report whether installation succeeds.

- Removed the accessibility service, its screen-control settings and fallback.
- Updated the connection message in all five supported languages.
- Signed with the same certificate as 0.5.8 to support updates over existing installations.

Release compilation and Android release lint checks passed. The unit-test task reports no test sources. No physical-device installation test has been completed for this version.
